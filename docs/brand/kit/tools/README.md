# Brand generation scripts

Scripts used to build the brand directions (`build.py`, `gen_index.py`…) and the final kit (`kit*.py`, `kit_renders.js`, `fav.py`).
They were written in a throwaway scratch directory: some paths are hard-coded to it and must be adjusted before re-running.
Requirements: Python 3 with fontTools (wordmark outlining), Node with Playwright (renders and screenshots).
