Poster → detail (shared element)

Click a poster. The poster itself travels to its place on the detail page while the rest of the grid fades out and the atmosphere fades in. Close (or Esc) reverses it. Product: View Transitions API with view-transition-name: poster-<id>; this demo uses the equivalent FLIP with WAAPI so it runs everywhere.

poster: transform 300 ms ease-in-out (0.77, 0, 0.175, 1) · grid: opacity 150 ms · atmosphere: opacity 250 ms ease-out · copy: opacity + 8 px rise 200 ms ease-out, delay 120 ms · reverse: 250 ms · reduced: 150 ms crossfade, no travel

Grid entrance (stagger)

First paint of a view only, never on scroll or filter changes (virtualised rows appear instantly). 24 ms per item, capped at 12 items (≈ 290 ms total), 250 ms ease-out, 12 px rise.

Value moves with a 900 ms ease (no jumps when updates arrive every 1–2 s). A soft sheen crosses the filled part every 2.4 s, then rests 30 % of the cycle. No opacity pulsing, no colour change. Reduced motion: no sheen, value still updates.

Press: scale 0.97 (icons 0.94) with the snappy spring, 230 ms, released instantly when the pointer lifts. Hover lift on posters: −4 px and 1.5 % with the gentle spring. Switch knob and checkmark: pop spring (9 % overshoot). Hover effects are gated behind (hover: hover) in product.

Toast with Undo, skeleton → content

Coldharbour 2016

The action applies at once (optimistic). Toast arrives in 330 ms (gentle spring, 16 px rise), stays 8 s, timer pauses on hover/focus, leaves in 150 ms. Undo restores the row with a 150 ms fade. ⌘Z works while the toast is visible.

Skeletons match the final layout. Shimmer: 1.6 s sweep, 40 % rest, staggered 60 ms per item. Content crossfades in over 250 ms; no layout shift. Reduced motion: static skeleton, fade only.
