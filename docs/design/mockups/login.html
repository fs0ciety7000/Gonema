Forgot the password?

Gonema has one admin account and no reset by e-mail. Whoever runs the server can make a new one:

  1. Stop Gonema.
  2. Remove the account from the users table of gonema.db.
  3. Start it again: this page offers to create the account anew.
Films, settings and connections are kept. The API key goes with the account: put the new one in the apps that use it.
